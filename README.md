# Landing-for-Build-Wise

A modern landing page for Build Wise construction company.

## About

Simple and clean landing page built with vanilla HTML, CSS and JavaScript for a construction company.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```
├── index.html          # Main page
├── style.css           # Styles
├── script.js           # JavaScript functionality
└── assets/             # Images and icons
    ├── Logo.png
    ├── *.jpg           # Project photos
    └── *.svg           # Icons
```

## Getting Started

Just open `index.html` in your browser or run a local server:

```bash
# If you have Python installed
python -m http.server 8000

# If you have Node.js installed
npx serve .
```
